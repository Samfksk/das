# Self Aim (ESX-kompatibel)

Detta är ett enkelt FiveM-script som låter spelaren rikta vapnet mot sig själv. När du väl siktar mot dig själv:

- **G** skjuter dig själv.
- **H** lägger ner vapnet (avbryter själv-siktning).

## Installation

1. Lägg mappen `self-harm` i din `resources`-katalog.
2. Lägg till i `server.cfg`:

```
ensure self-harm
```

## Användning

- Skriv `/selfaim` för att börja sikta vapnet mot dig själv.
- Tryck **G** för att skjuta dig själv.
- Tryck **H** för att sluta sikta.

Scriptet är klientbaserat och påverkar bara din egen ped. Det kräver inte något särskilt ESX-API, men fungerar tillsammans med ESX.
